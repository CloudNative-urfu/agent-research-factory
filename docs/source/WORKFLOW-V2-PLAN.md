## Обязательные границы

Пилотные данные не используются как confirmation. Научный отрицательный исход
не равен ошибке API. Победитель по прежним gates; полезные отрицательные материалы
выводятся отдельно. Завершённые и неизвестные запросы автоматически не повторяются.
Нет обещания exactly-once для внешнего API при обрыве после отправки.
