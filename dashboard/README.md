# Монитор кампании

Python 3, только стандартная библиотека. Установка зависимостей не нужна.

Из корня проекта:

```sh
python3 research-dashboard/dashboard.py ~/.local/share/research-campaigns/defense
```

Открыть http://127.0.0.1:8788. Остановка — Ctrl+C. Другой порт: `--port 8789`.

Сайт показывает состояние, модели, стадии, документы каждого цикла, критику,
активность файлов и последнюю предварительную проверку. Обновляется каждые 5 секунд.
Снятая галочка «Следить за текущим циклом» позволяет изучать прошлые итерации.
Не изменяет кампанию и не отправляет запросы моделям. HTML из артефактов не исполняется.
Время последней записи не является гарантией работоспособности процесса.

## Оповещения

Нажми «Включить сигналы» и разреши уведомления браузера. При сохранённом решении
критика о завершении цикла появятся сообщение, тройной звуковой сигнал и системное
уведомление (если разрешено). Также оповещается окончание всей кампании.
«Проверить сигнал» позволяет проверить звук и уведомления без изменения кампании.
Результат `pivot` или `blocked` тоже считается завершением оценённого цикла,
а не успешным научным результатом; решение критика указано в сообщении.

Страница должна оставаться открытой. Браузер может задерживать опрос в фоновой
вкладке или приостанавливать его во сне. После перезагрузки страницы звук нужно
включить снова. Уже завершённые на момент открытия циклы не вызывают сигнал;
повторные обновления не повторяют уведомление. На нескольких открытых вкладках
оповещение может сработать в каждой — включай звук в одной.

Проверки:

```sh
python3 -m unittest discover -s research-dashboard
```
